How this site works

Every fact links to where it came from. Two bounded exceptions exist, and this page is their explanation.

Match facts

Scores, lineups, referees and scoring events are parsed from Wikipedia articles (CC BY-SA 4.0) — each match-detail page footer links the exact source article and notes that the data was "parsed and normalised from wikitext". Where the historical record is thin we say "not recorded" rather than guessing (principle 6: no invented facts).

Future fixtures come via API-Sports. There is no public per-record page for an API fact, so the "viewable source" is a provenance note instead: the named source and the fetch timestamp, e.g. "Fixtures via API-Sports, fetched 2026-08-01".

Sources that disagree

When two display-cleared sources disagree on a fact, both values are stored and the precedent value is shown with a "sources differ" badge linking both — never silently picked. Kaggle is logged as a cross-check only until its licence clears, and is never displayed.

The two exceptions to "every fact is sourced"

Derived facts — values this site computes itself (sentiment scores). They carry a distinct "computed" badge plus a pair of links: a method link (this page) and a source link (the thread or articles it was computed from). Inference is allowed only inside this badged class, never in match facts.

API-provided facts — fixtures with no public per-record page to link. Their "viewable source" is the provenance note described above: named source + fetch timestamp.

Fan mood (computed)

Mood scores are computed by this site with a public sentiment lexicon, scored over r/rugbyunion match-thread comments where a thread exists, or news headlines where it doesn't. Scores map to a closed five-label vocabulary:

  • Despair — score in [-1, -0.6)
  • Grumbling — score in [-0.6, -0.2)
  • Mixed — score in [-0.2, 0.2]
  • Upbeat — score in (0.2, 0.6]
  • Euphoric — score in (0.6, 1]

Minimum volume: fewer than 25 comments (Reddit) or 5 articles (Guardian) renders "too little discussion to score" instead of a number — a thin thread is not enough evidence for an inference.

Mood is our inference, never the source's own words — that's why it always carries the "computed" badge and is phrased as "computed by this site from X", never "Reddit says" or "the Guardian says".

Sentiment is explicitly a modern-era feature: older matches predate any mood source and show an honest "no sentiment sources for this era" note on the timeline instead of a padded guess.

How the derived figures are computed

Home's form guide, History's record by era, and the detail head-to-head strip are arithmetic over facts already displayed and individually sourced on this site — not inference — so none of them carry the "computed" stamp above. Instead every one carries a plain-text caption stating its denominator and what was excluded, e.g. "Win % of the 128 tests in this era with a recorded result; 6 further tests have no recorded result." No such figure ever renders without its caption. Rows with no recorded result are always counted into a visible "not recorded" segment and excluded from any percentage — never guessed.

The score-progression chart is the one figure among the four that is gated rather than merely captioned: it uses an era points table held as an app constant, and renders only if every scoring event in a match is timed and the running reconstruction reconciles exactly to the stored final score. Matches before 1894 are never charted — the points values changed three times between 1890 and 1894, and we will not encode values we cannot verify per fixture. Where the gate fails, the page states the reason and the ordinary events list stands in its place; the events list is never replaced by the chart, only ever supplemented by it.

Attribution

Wikipedia-derived match data is carried and displayed under CC BY-SA 4.0 with per-page attribution: the exact source article link, the licence link, and a note that it was modified (parsed and normalised from wikitext). The history list page carries one site-level attribution to the source list article. This site offers no bulk data download, which keeps the licence question contained to what pages display.
